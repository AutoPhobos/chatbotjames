## 🚀 Core Features

* **100% Local Inference**: Powered by `Transformers.js`. Once synced, the system operates entirely client-side. Zero API keys. Zero latency[cite: 1].
* **Persistent Cognition**: Integrated `localStorage` engine preserves thread history and custom knowledge cores across reboots[cite: 1].
* **Privacy-Hardened**: Zero telemetry. No server-side logging. No external tracking[cite: 1].
* **Aesthetic Immersion**: A mobile-first, cybernetic terminal interface designed for low-light, high-focus environments[cite: 1].

## 🛠️ Deployment & Installation

### Web Deployment
Optimized for **Render.com**, **Vercel**, or **GitHub Pages**[cite: 1].
URL: [https://chatbotjames.onrender.com/](https://chatbotjames.onrender.com/)[cite: 1]

Ensure the following stack is in your root directory:
* `index.html`, `style.css`, `app.js`, `worker.js`, `manifest.json`[cite: 1].

### PWA Installation
1. Navigate to the deployment URL[cite: 1].
2. Select **"Install App"** via the browser bar or Share menu[cite: 1].
3. Launch as a standalone tactical application[cite: 1].
