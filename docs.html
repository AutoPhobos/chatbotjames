Getting Started

Simply open JAMES in any modern browser supporting WebGPU. The application loads models and dependencies directly into your browser cache on first launch.

Available Tools

JAMES can invoke various browser-native tools to fetch live data and perform utility tasks:

  • 🔍 search — Real-time web search summaries.
  • 🌤️ weather — Current weather conditions and forecasts.
  • 💱 currency — Live currency exchange rate calculations.
  • 📚 wikipedia — Concise summaries from Wikipedia.
  • ⏰ time — Accurate time and timezone lookups.
  • 🔑 uuid — Generate unique identifiers.
  • 🔐 password — Secure local password generation.
  • 🎨 palette — Color palette generation and manipulation.
  • ⏳ timer — Local countdown timers.
  • 📋 clipboard — Clipboard utility operations.

System Modes

  • Full Mode: Full model capabilities with all integrated tools enabled.
  • Lightweight Mode: Optimized for lower-spec hardware with streamlined tool execution.
  • TV Mode: Tailored UI layout for big screens and keyboard or remote navigation.

Privacy & Security

Because JAMES runs entirely client-side via WebAssembly and ONNX Runtime, your conversations never touch a remote database. Every session is ephemeral and self-contained on your machine.
